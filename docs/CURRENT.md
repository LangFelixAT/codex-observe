## Product State

Codex Observe is currently a local-first workbench for understanding Codex session cost and context growth. A user landing on an empty dashboard sees copy-pasteable next actions for synthetic demo data, local ingestion, and database health checks. A user can generate synthetic demo data with contrasting high- and low-risk runs, inspect the dashboard, browse large histories in bounded 50-conversation pages with range-aware Previous/Next navigation, and narrow them with the sidebar Find session search plus composable Risk and Focus filters, download aggregate-only reports and comparisons from the Overview, export aggregate-only reports with multi-day session checkpoint recommendations when real runs span durable work phases, compare runs, collect visual QA evidence, and produce a one-command public evidence bundle with a human-readable index without scanning private logs.

The primary experience is answer-first: CLI help and the README expose exactly two start paths, plain `codex-observe tour` stays concise around diagnosis, habit, and proof target while `tour --reviewer` carries optional reviewer material, and `codex-observe paths` presents the human-readable private review before JSON automation. Session listings put the selected run, explicit risk-band tie-breaker, primary driver, evidence, habit, and target before the inventory table. The dashboard renders the same report-derived operator briefing before metrics, and synthetic plus ignored real-profile visual QA prove it is fully visible in the initial desktop and narrow viewports.

The exhaustive reviewer loop is printed by `codex-observe tour --reviewer` with a top-level review checklist, evidence, success checks, and a terminal feedback handoff plus a final terminal `Next commands` footer; `codex-observe tour --json` exposes the same synthetic-data commands, including plain terminal handoff commands, `review_path`, `feedback_handoff`, and per-step success checks as a schema-versioned automation contract.
